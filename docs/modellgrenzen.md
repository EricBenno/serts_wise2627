# Modellgrenzen (mit Verzerrungsrichtung) – Baustein für den Bericht

| Grenze | Wirkung |
|---|---|
| Speicher als ein Energiespeicher; Temperatur nur über die Jahresregel „≤ 53 % direkt“ | Speichernutzung eher überschätzt (Schichtung/Mischung nicht abgebildet; einzelne Stunden können unrealistisch sein) |
| Speicherverlust ∝ Inhalt, kein Erdreich | Anfahrjahre unterschätzt, Spätjahre leicht überschätzt |
| Kleines PTES (≈ 6.000 m³) mit Verlustrate aus DRL (60.000 m³) | Verluste eher unterschätzt → Sensitivität bis 8·10⁻⁵ 1/h |
| Perfekte Voraussicht (LP über 8760 h) | Betrieb und Solaranteil eher überschätzt, Kosten unterschätzt |
| Kollektor bei fester mittlerer Temperatur (67,5 °C), ohne Einfallswinkelkorrektur | Ertrag ± (Winter/Morgen eher überschätzt) |
| Kollektorkennwerte angenommen (Keymark nicht abrufbar) | Ertrag ± 5–10 % |
| Wetterjahr 2022 strahlungsreich (PVGIS 1.394 kWh/m² auf 35°) | Solarertrag/-anteil ggü. Normaljahr überschätzt (grob +20–30 %) |
| Konstanter COP aus dem Speicher (4,5) | Herbst unterschätzt, Frühjahr überschätzt; Jahresmittel ok |
| WP-Leistung unabhängig von Quelltemperatur (nur Luft unter −7 °C aus) | WP-Leistung bei Kälte eher überschätzt |
| Lastgang aus Standardprofilen (NB, Wetter Münster 2022) | Spitzen geglättet; Kopplung Kälte ↔ Last nur statistisch |
| Lineare Investkosten (Speicher 105 €/m³ für ≈ 5.000–12.000 m³) | Optimum außerhalb dieses Bereichs ungenau |
| Netzverluste aus NB (80/50 °C), Modell 80/45 °C | vernachlässigbar |
